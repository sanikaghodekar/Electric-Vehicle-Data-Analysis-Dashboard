🚗 Electric Vehicle Data Analysis Dashboard (Tableau)
## Project Overview ##

This project presents an Electric Vehicle (EV) Data Analysis Dashboard built using Tableau Public.
The dashboard provides insights into electric vehicle adoption trends across different states, manufacturers, models, years, and CAFV eligibility.

It is designed to help users understand:
- Growth of EVs over time
- Markey domainace by manufacturers and models
- State-wise distribution of EVs
- Comparison between BEV and PHEV vehicles
  
📊 Dashboard Highlights

🔹 Key Metrics

- Total Vehicles: 150,422
- Average Electric Range: 67.83 miles
- Total BEV Vehicles: 116,750
- Total PHEV Vehicles: 33,672

🔹 Visualizations Included

- Top 10 Vehicles by Make
- Total Vehicles by Model
- Vehicle Trend by Model Year
- CAFV Eligibility Distribution
- State-wise EV Distribution (Map View)

Filters:

- State
- EV Type (BEV / PHEV)
- CAFV Eligibility

🛠 Tools & Technologies

- Tableau Desktop Public Edition
- Data Visualization & Analytics
- Mapbox & OpenStreetMap (for geo visualization)
